# Simple JRPG

Semester project for the Informatics 2 course.

A turn-based JRPG game built in Java to practice Object-Oriented Programming (OOP) concepts like inheritance and polymorphism. Players manage health and mana while fighting waves of enemies using physical attacks, magic spells, and items.

## Features
* Turn-based combat system
* Wave-based enemy progression
* Basic Graphical User Interface (Java Swing)
* OOP-based design for characters, attacks, and inventory items

## Tech Stack
* Java (Swing)

## How to Run
1. Open the project in any Java IDE (e.g., IntelliJ IDEA).
2. Run `src/Main.java`.
